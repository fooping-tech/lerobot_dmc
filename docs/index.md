# LeRobot DMC ドキュメント

このサイトは `dmc_robo` 用プラグインと GUI テレオペの仕様・運用情報をまとめたものです。

## よく使うドキュメント

- `overview.md`：全体概要（現行仕様）
- `serial_controller_software_spec.md`：シリアル統合の仕様書
- `serial_controller.md`：シリアル入力の運用手順
- `remote_ui.md`：GUIテレオペの使い方
- `lerobot_dmc_robo_usage.md`：LeRobot CLI からの利用手順
